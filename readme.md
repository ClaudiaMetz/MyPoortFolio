# 👩‍💻 Claudia Metz | Portfolio

A personal portfolio exploring technology through projects, experimentation, and continuous learning.

## 🧭 About

This portfolio brings together projects developed through academic work, independent exploration, and hands-on experimentation with different technologies.

It reflects my interest in understanding how things work, exploring connections between disciplines, and turning ideas into practical projects.

Projects are organized into three main areas:

- **🌐 WEB 2:** Web development and applications.
- **⛓️ WEB 3:** Blockchain, smart contracts, and decentralized applications.
- **📊 DATA & AI:** Data science, analytics, and artificial intelligence.

The portfolio also features **integrative projects**, combining concepts and tools from different areas to take an idea from its initial stage to a working, deployable MVP.

## 🎨 Design Approach

The portfolio was deliberately conceived with a minimalist, clean, and straightforward design, keeping the focus on the projects rather than the platform presenting them. The interface is intentionally simple, allowing the work itself to take center stage.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## ⚙️ Technical Approach

Built with a lightweight, static architecture, without frameworks or build dependencies.

The site uses an interactive flip-card interface to present projects, with additional information available on each card's reverse side.

## 🔄 Status

An ongoing project that evolves alongside my learning and experimentation. Its content, projects, and implementation continue to grow and change over time.
